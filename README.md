# GDG Silicon Maze

A monorepo of projects for GDG Silicon Maze.

| Folder | What it is |
|--------|------------|
| [`last_portfolio/`](last_portfolio/) | The Last Portfolio, a survivor's-terminal personal portfolio site (plain HTML/CSS/JS) |
| [`jarvis/`](jarvis/) | Jarvis (work in progress) |

## Deploy

`.github/workflows/pages.yml` publishes the `last_portfolio/` site to GitHub Pages on every push to `main`.
